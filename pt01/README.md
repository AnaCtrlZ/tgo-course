# Лабораторная работа 01. Языковая модель из счётчиков и свой BPE

Один скрипт `pt01/run.py` скачивает фиксированный корпус «Война и мир», строит
биграммную языковую модель со сглаживанием Лапласа, оценивает её на отложенной
части и обучает BPE-токенизатор на всём корпусе. Используется только стандартная
библиотека Python.

Запуск:

```bash
python pt01/run.py            # полный прогон: 1500 слияний BPE
python pt01/run.py --fast     # быстрый прогон: 200 слияний BPE
```

Результаты пишутся в `pt01/artifacts/bigram.json` и `pt01/artifacts/bpe.json`.

## 1. Что сделано

**Корпус и слова.** Текст скачивается по зафиксированному URL, приводится к
нижнему регистру, «ё» заменяется на «е», слова выделяются регулярным выражением
`[а-я]+(?:-[а-я]+)*`; цифры и пунктуация при этом отбрасываются. Последние 10 %
слов (не предложений) отложены: модель их не видит. На обучающей части считаются
частоты слов и пар соседних слов.

**Биграммная модель.** Класс `BigramModel` хранит счётчики и по запросу считает
долю со сглаживанием Лапласа:

```
P(w | v) = (c(v, w) + α) / (c(v) + α · V),   V — размер обучающего словаря.
```

Реализованы методы `fit`, `prob(v, w)`, `logprob(words)` и `generate`. `prob` и
`logprob` принимают необязательный `α`, поэтому одни и те же счётчики оцениваются
при разных силах сглаживания. Первое слово при подсчёте правдоподобия не
оценивается: у него нет предыдущего контекста.

**Генерация.** Следующее слово выбирается случайно из строки предыдущего слова:
вероятности возводятся в степень `1/T` и нормируются заново. Для каждой пары
«температура × стартовое слово» (`0.5`, `1`, `2` × «князь», «она») строится текст
из 30 слов. Генератор инициализирован фиксированным seed, поэтому все шесть
образцов воспроизводимы.

**Правдоподобие.** Первые 12 слов отложенной части считаются «связным
предложением»; те же слова перемешиваются фиксированным seed. Для обоих вариантов
при `α = 0.01` считается `Σ log P(w_t | w_{t-1})`, а также число пар, которых не
было в обучении.

**Перплексия.** На всей отложенной части считается

```
PPL = exp( -1/N · Σ log P(w_t | w_{t-1}) ),   N = число переходов,
```

при `α ∈ {1, 0.1, 0.01}`; первое слово не оценивается.

**BPE.** Класс `BPETokenizer` разбивает каждое слово на буквы, добавляет маркер
конца слова `</w>`, находит самую частую пару соседних символов во всём словаре,
сливает её и повторяет. Слова с частотой ниже порога (2 в полном режиме, 3 в
`--fast`) в обучении не участвуют. Счётчики пар и обратные индексы обновляются
инкрементально — заново разбираются только слова, содержащие победившую пару.
Затем выученные слияния применяются ко всем словам корпуса: на каждом шаге
сливается пара с наименьшим номером в списке слияний. Разбиения кэшируются по
типам слов. В `bpe.json` сохраняются сами слияния (это и есть токенизатор),
размер BPE-словаря, статистика сжатия и примеры разбиения.

### Перплексия и выбор α

| α | Перплексия на отложенных 10 % |
|---:|---:|
| 1 | 15 749.03 |
| 0.1 | 7 744.25 |
| 0.01 | 5 310.22 |

Лучшее из проверенных значений — `α = 0.01`. При `α = 1` к знаменателю каждого
контекста добавляется `α · V ≈ 45 309` псевдосчётов: распределение сильно
размазывается по всему словарю, и даже частые пары получают заниженную
вероятность. При `α = 0.01` добавляется всего около 453 псевдосчёта: редкие, но
реальные пары сохраняют вес, а невиденные пары всё ещё получают ненулевую
вероятность, поэтому логарифм не уходит в минус бесконечность. Слишком большое
сглаживание вредит именно тем, что «разбавляет» уверенные предсказания почти
равномерным шумом по 45 тысячам слов. При этом абсолютные значения перплексии
велики: биграмма не учитывает длинный контекст, а 8.07 % отложенных слов вообще
не встречались в обучении (3 496 токенов, 2 808 типов), поэтому каждое такое
слово стоит примерно `log(1/V) ≈ −10.7` ната.

### Правдоподобие связного и перемешанного текста (α = 0.01)

Связное предложение (первые 12 слов отложенной части):

```
был георгий й степени на другой день были у фельдмаршала обед и
```

Те же слова после перемешивания:

```
и у георгий был фельдмаршала й день на другой обед были степени
```

| Величина | Значение |
|---|---:|
| `logprob_sentence` | −85.9478 |
| `logprob_shuffled` | −105.6904 |
| Разница | 19.7426 ната |
| Средний лог на переход (11 переходов) | −7.8134 против −9.6082 |
| Пар, не встречавшихся в обучении | 5 из 11 |

Связный текст правдоподобнее перемешанного почти на 20 натов. Пять пар из
одиннадцати в «предложении» не встречались в обучении; без сглаживания каждая
из них дала бы `log 0 = −∞`, и сравнение было бы невозможно. Сглаживание - необходимое условие для самой постановки задачи.

### Генерация при разных температурах

`T = 0.5`, старт «князь» — распределение сконцентрировано, модель зацикливается
на самых вероятных продолжениях:

```
князь андрей безвыездно поджимавшая мастерское николы императору и вдруг вспомнил о том что он не только в этот день князь андрей но его и в москву то что он будет
```

`T = 1`, старт «князь» — разнообразие выше, но связность быстро теряется:

```
князь василий готовностью коротенькие будущность путался визгом эскадронному уланский сенях рысаком материальных пристреливали ропот одержанной везлись последовательно краем полно насмешек фуража другими русскими проиграна пети видом длиннополым чатров зажигать давивший
```

`T = 2`, старт «князь» — почти равномерный выбор по словарю, редкие и
несочетаемые слова:

```
князь доказывающие попротивоборствую духовному гвардейцами трогательно-невинное крещенья июля памятью прозрел призываем скорее зевая недоразумениях марии откровенною повторяет поспело вечному мерзости прусаки близкие расстроились приятного наивный нечищеные знаменитые рапортам одержала значили
```

При `T = 0.5` видны осмысленные локальные биграммы («князь андрей», «в этот
день»), но текст повторяется. При `T = 1` появляются правдоподобные начала
(«князь василий»), затем модель уходит в случайные продолжения. При `T = 2`
температура фактически уничтожает сигнал: редкие слова встречаются почти так же
часто, как частые. Все шесть образцов лежат в `bigram.json` (поле `generation`),
включая старты «она» при каждой температуре.

### BPE-токенизатор

Полный прогон: 1 500 слияний, BPE-словарь из 1 520 токенов (с маркером `</w>`).

| Показатель | Значение |
|---|---:|
| Символов в словах корпуса | 2 245 342 |
| Слов (токенов корпуса) | 433 082 |
| BPE-токенов | 835 133 |
| Токенов на слово | 1.9283 |
| Во сколько раз токенов меньше, чем букв | 2.6886 |

Разбиение слов из `examples`:

| Слово | Токены |
|---|---|
| наполеон | `наполеон</w>` |
| сказала | `сказала</w>` |
| неудовольствие | `не` · `уд` · `оволь` · `ствие</w>` |
| князь | `князь</w>` |
| андрей | `андрей</w>` |
| противный | `прот` · `ив` · `ный</w>` |

Первые слияния — `о</w>`, `и</w>`, `е</w>`, `а</w>`, `ст`, `я</w>`, `ь</w>`,
`ал`, … То есть BPE сразу выучивает русские окончания и частые буквосочетания;
к 1 500 слияниям частые слова становятся одним токеном, а длинное
«неудовольствие» распадается на морфемоподобные куски.

Дополнительно я обучила токенизатор на 300 и 5 000
слияний теми же счётчиками (отдельные артефакты не сохраняла):

| Слияний | BPE-словарь | Токенов на слово | Сжатие | Слов одним токеном (типы / вхождения) | «неудовольствие» |
|---:|---:|---:|---:|---:|---|
| 300 | 334 | 2.8874 | 1.7956 | 0.2 % / 32.7 % | `не` `уд` `ов` `ол` `ь` `ст` `ви` `е</w>` |
| 1 500 | 1 520 | 1.9283 | 2.6886 | 1.0 % / 54.0 % | `не` `уд` `оволь` `ствие</w>` |
| 5 000 | 4 963 | 1.4653 | 3.5382 | 4.6 % / 71.3 % | `не` `удовольствие</w>` |

Граница «слово целиком / по буквам» проходит по частоте: уже при 1 500 слияниях
больше половины словоупотреблений — один токен, хотя одним токеном являются лишь
1 % типов. Редкие слова остаются разбитыми даже при 5 000 слияний (4.6 % типов),
потому что BPE оптимизирует суммарную частоту, а не покрытие словаря. При 5 000
слияний «неудовольствие» удачно делится на приставку `не` и основу
`удовольствие</w>`.

### Выводы

«Обучение» действительно свелось к подсчёту: доли пар дают распределение
следующего слова, а сглаживание — это добавка псевдосчётов. Для этого корпуса и
словаря из 45 тысяч слов `α = 0.01` заметно лучше `α = 1`; связный текст
правдоподобнее перемешанного на 19.7 ната, хотя пять пар из одиннадцати модель
никогда не видела. Температура управляет компромиссом «повторяемость ↔
разнообразие»: 0.5 зацикливается, 2 разрушает связность. BPE без внешних
библиотек выучивает окончания первыми, сжимает текст в 2.69 раза и оставляет
частые слова целыми, а редкие — по частям.

## 3. Что не получилось и почему

**Перплексия велика (5 310 даже при лучшем α).** Причины принципиальные, а не
технические: аддитивное сглаживание с `V = 45 309` — грубый сглаживатель, а
биграмма не видит контекста длиннее одного слова. Кроме того, отложенный хвост —
это философский эпилог с заметно другим словарём; 8.07 % его токенов не
встречались в обучении.

**«Связное предложение» не является чистым предложением.** По условию отложенная
часть отрезается по словам, поэтому первые 12 слов начинаются с «был» (середина
фразы) и пересекают границу предложения. В исходном тексте стоит «Георгий 1-й
степени»; регулярное выражение выбрасывает цифру, и от «1-й» остаётся отдельный
токен «й».

**Редкие слова не участвуют в обучении BPE.** Слова с частотой ниже порога
(2 или 3) не влияют на выбор слияний, но при применении всё равно разбиваются
выученными правилами. Поэтому для гапаксов разбиение может быть неоптимальным:
модель оптимизировала частые слова. Это осознанный компромисс ради скорости,
разрешённый условием.
